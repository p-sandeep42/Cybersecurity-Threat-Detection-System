# ThreatWatch

A cybersecurity portfolio project for detecting and investigating suspicious authentication activity.

- [Run or upgrade the local demonstration](rebuild/README.md)
- [Product, architecture and implementation plans](docs/plan/README.md)

The rebuild lives in `rebuild/`. It includes an owner dashboard, event API, three authentication rules, an experimental automation rule, opt-in interaction summaries, retention tools, a separate demo application, and reproducible evaluation/browser tests. See the implementation README for measured results and limitations.
